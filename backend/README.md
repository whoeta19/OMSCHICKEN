# OMSFinance

**Карманная бухгалтерия для малого и среднего бизнеса в РФ.**
Минималистичный премиальный интерфейс в эстетике «тихой роскоши»: глубокий белый фон, глубокий океанский синий акцент, жирная современная типографика, мягкие анимации.

Проект состоит из двух частей:

- `backend/` — API на **NestJS 11 + PostgreSQL 16 + Prisma 6** (ИИ-ассистент на Anthropic SDK).
- `ios/` — приложение на **SwiftUI (iOS 17+)** с архитектурой на `@Observable`-роутере.

## Структура репозитория

```
omsfinance/
├── docker-compose.yml          # API + PostgreSQL + Redis + MinIO
├── backend/                    # NestJS API (см. backend/README.md)
│   ├── prisma/                 # схема БД и сиды
│   └── src/modules/            # auth, documents, tax, tasks, fns, assistant
└── ios/OMSFinance/
    ├── App/                    # точка входа, RootView
    ├── DesignSystem/           # Palette, Typo, LuxuryCard, анимации (Motion, appear, PulseLoader)
    ├── Core/
    │   ├── Navigation/         # Route, AppRouter, DestinationView, RootView (TabBar + шестерёнка)
    │   └── Networking/         # APIClient (actor), TokenStore
    ├── Models/                 # DTO
    └── Features/
        ├── Onboarding/         # приветствие + вход (Яндекс/Apple/ЭЦП)
        ├── Tasks/              # вкладка «Задачи» + деталь
        ├── Tax/                # вкладка «Налог»: ЕНС, НДС, вычеты
        ├── Create/             # вкладка «Создать»: чат-ассистент, предпросмотр, контрагент
        ├── Documents/          # вкладка «Документы» + карточка
        ├── FNS/                # вкладка «ФНС»: письма/требования, отчёты
        └── Settings/           # организации, печать/подпись, счета, тема
```

## Архитектура навигации (iOS)

Навигация построена вокруг единого источника истины — `AppRouter` (`@Observable`, `@MainActor`):

- **`Tab`** — пять вкладок: Задачи, Налог, Создать (по центру), Документы, ФНС.
- **`Route`** — один `Hashable`-enum, описывающий все экраны приложения.
- **`AppRouter.paths: [Tab: [Route]]`** — отдельный стек навигации на каждую вкладку, чтобы они не «перемешивались».
- **`DestinationView`** — единственная точка маппинга `Route → экран`. Новый экран = один `case` в `Route` + одна ветка здесь.
- **Глубокие ссылки** (`handleDeeplink`) — навигационные задачи открывают нужную вкладку и экран (`create`, `tax/<period>`, `documents/<id>`).
- **Настройки** открываются модально из блеклой шестерёнки в правом верхнем углу.

### Анимации

Единые токены в `DesignSystem/Animations.swift`:

- `Motion.soft / .snappy / .fade` — общие spring-кривые;
- `.appear(index)` — каскадное появление карточек (fade + slide + scale);
- `PressableStyle` (`.buttonStyle(.pressable)`) — отклик кнопок;
- `PulseLoader` — индикатор «ассистент думает»;
- переключение вкладок и фаз (онбординг ↔ основной экран) — через `withAnimation(Motion.soft)`, `matchedGeometryEffect` в кастомном таб-баре, `contentTransition(.numericText())` для крупных сумм.

## Запуск backend

```bash
cp backend/.env.example backend/.env     # заполнить секреты (минимум ANTHROPIC_API_KEY)
docker compose up --build                # API на http://localhost:3000
docker compose exec api npm run prisma:seed   # демо-данные (опционально)
```

Swagger: <http://localhost:3000/docs>. Подробности — в `backend/README.md`.

## Запуск iOS

Требуется **Xcode 16+** и **iOS 17+**.

1. Создайте новый проект в Xcode (App, SwiftUI, имя `OMSFinance`) или используйте Swift Package, затем добавьте содержимое папки `ios/OMSFinance/` в таргет (сохранив структуру групп).
2. Базовый адрес API задаётся в `Core/Networking/APIClient.swift` (`API.baseURL`, по умолчанию `http://localhost:3000/api/v1`).
   - Для симулятора подойдёт `localhost`; для устройства укажите IP машины с backend и при необходимости разрешите HTTP в `Info.plist` (`NSAppTransportSecurity`).
3. Запустите backend (см. выше) и соберите приложение.

> Экраны работают и без backend: каждый ViewModel при недоступности API подставляет демонстрационные данные, так что интерфейс и навигацию можно посмотреть сразу.

## Функциональность

- **Онбординг и вход** — Яндекс, Apple, ЭЦП.
- **Задачи** — крупный блок «к уплате» сверху, ниже налоговые/отчётные и навигационные задачи.
- **Налог** — сальдо ЕНС небольшим шрифтом, НДС к уплате крупно, входящий/исходящий НДС, варианты вычета по документам без счетов-фактур.
- **Создать** — чат с ИИ-ассистентом для составления первички. Структурированный сбор данных: бот знает какие поля нужны для каждого типа документа (контрагент, ИНН, позиции с количеством/ценой/ставкой НДС), принимает данные хоть одним сообщением хоть по частям, показывает прогресс заполнения и предупреждает что ещё нужно. Генерация в PDF и XML по форматам ФНС, добавление печати и подписи.
- **ФНС** — письма, требования, отправленные отчёты в ФНС/СФР/ПФР/ЕФС со статусами приёма.
- **Настройки** — добавление организаций, печать/ЭЦП, подключение расчётных счетов для выписок, тема оформления.

## Замечания

Это production-ready скаффолд: чистая модульная структура, типобезопасность, единая навигация и дизайн-система. Перед боевым использованием подключите реальные интеграции (оператор ЭДО, ЕГРЮЛ/ЕГРИП, банки), вынесите токены в Keychain и сверьте XML-форматы с актуальными приказами ФНС.
